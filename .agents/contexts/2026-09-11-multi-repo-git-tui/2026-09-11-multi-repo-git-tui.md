# Multi-repo git TUI tooling

[[DOTFILES]]

## Purpose

Выбрать инструментарий для управления множеством git-репозиториев: общий список,
ворктри, отставание от мастера, массовый fetch/pull.

Краткий вывод: единого инструмента под все четыре сценария нет. Ворктри — слепое
пятно у всех multi-repo инструментов. Рабочая гипотеза — связка `gita` + `gwq`,
либо свой скрипт на ~15 строк.

## Load policy

Загружать, когда речь о навигации или пакетных операциях по множеству репозиториев.
Ресерч — снимок на 2026-09-11; перед установкой перепроверить даты последних коммитов,
особенно у `gwq` и `mani`.
