# Agents Context v2 — решения

Принято за одну сессию 2026-08-15. Каждое из них однажды было решено иначе, поэтому
записан не только выбор, но и причина, по которой предыдущий вариант отпал.

## Доктрина

Папки существуют для менеджмента, не для структуры. `.agents/` — реалм: физический
слой хранения, который едет вместе с репозиторием. Контекст внутри — сабреалм.

Заметка ничего не знает о папке, в которой лежит. Отсюда всё остальное: плоские
ссылки, уникальные по всему реалму имена, отсутствие адресации через каталоги.

Источник — заметки `🕸 Realm` и `🕸 Zettelkasten 1.1 - ящики или реалмы` в обсидиановом
волте пользователя. Не выдумывать конвенцию заново, а применить существующую.

## Что отменено и почему

| Решение | Причина отмены |
|---|---|
| Генерируемый `INDEX.md` | Индекс — это обратные ссылки хаба. Отдельный файл был лишней сущностью, которую надо синхронизировать |
| Глобальное правило в `.rulesync-global/rules/` | Всегда включено во всех репозиториях ради двух. Правила уехали в рулбук внутри корпуса |
| Агентский хук на завершение хода | Валидация переехала внутрь `new`/`set`; фоновая машинерия не нужна |
| `read_first` во фронтматтере | Дублировал аннотированные ссылки в `## Files`, но без аннотаций. Инвариант «заметка не потеряна» стал проверкой графа |
| Поля `name` и `created` | Буквально имя папки, переписанное дважды. Проверка «имя папки == created + name» сверяла поле с самим собой |
| `zk` как индексатор | Три нужные проверки дешевле дописать самому, чем принести бинарь, конфиг, SQLite-кэш и вторую модель имён |
| Каскад разрешения корня, `--root`, реестр | Задача решается командой `cd`. Корень — всегда `./.agents` |
| Шаблон внутри скрипта | Markdown в питоновской строке невозможно поддерживать. Шаблоны — обычные файлы в скилле |
| Автопоиск хаб-заметки | Магия, которая однажды прицепится не к тому файлу. Имя выводится из имени репозитория |

## Что осталось

Схема: `updated`, `status`, `next`, `tags`. Слаг и дата рождения — имя папки, во
фронтматтере их нет.

Раскладка: `contexts/<created>-<slug>/`, входная заметка называется как папка,
остальные несут префикс даты и слаг контекста для родовых имён.

Ссылки: плоские имена файлов, только в теле, никогда во фронтматтере. Каждая входная
заметка линкует хаб, иначе выпадает из дерева.

Разделение слоёв: рулбук описывает инвариант, скилл описывает процедуру, валидатор
единственный, кто чем-либо ручается.

## Дефект, который стоил трёх заходов

Массовое переименование с заменой ссылок **по ходу** трижды увело ссылки в чужой
контекст того же рода: `2026-06-28-plan.md` существовал в пяти папках, замена брала
первое совпадение, и `mcp-stack` начинал ссылаться на план `agent-context-system`.

`check` этого не ловит и не может: такие ссылки резолвятся, просто не туда.
Ссылочная целостность и смысл — разные гарантии.

Лечение записано в `MIGRATION.md` скилла: все переименования сначала, полная карта
имён, один проход по ссылкам последним, затем отдельный аудит «ссылка на имя,
которого нет в собственной папке».
