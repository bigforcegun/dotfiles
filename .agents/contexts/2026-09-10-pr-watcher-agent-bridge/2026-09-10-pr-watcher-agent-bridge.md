# PR Watcher → Agent Bridge

[[DOTFILES]]

## Purpose

Собрать локальный мост: событие на GitHub PR доставляется в живую агентскую сессию, ревью-агент копит контекст по PR и предлагает комментарии, которые визирует человек.

Ключевой факт, определяющий всю конструкцию: на рабочих репозиториях
(`KosyanMedia/delta`, `gtu-internal-it/aviakit`) прав `admin` нет, поэтому
входящие вебхуки, GitHub App и Paseo Hub недоступны. Остаётся исходящий
поллинг плюс `paseo send` как последний хоп в живую сессию.

## Load policy

Загружать перед тем, как:

- проектировать или запускать демон `pr-watcher` (launchd, watchlist, state);
- подключать Paseo Hub, GitHub App или вебхуки к любому репозиторию;
- настраивать `paseo heartbeat` / `paseo schedule` для слежения за PR;
- решать, от чьего имени агент оставляет комментарии в pull request;
- строить доставку событий во внешне адресуемую агентскую сессию
  (`paseo send`, `codex queue`, `claude --from-pr`).

Не трогать в рамках этого контекста: рабочие репозитории. Ресерч про личный
тулинг, `.agents/` положен в dotfiles намеренно, а не в монорепу delta.
