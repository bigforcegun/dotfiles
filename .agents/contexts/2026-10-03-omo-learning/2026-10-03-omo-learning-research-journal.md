# Журнал исследования OMO

## Задание и формат

Запрос: учить пользователя OMO по четырём трекам и сохранять результаты через dot-agents-context. Формат: связанные Markdown-заметки в `.agents`, русский язык, практические объяснения; answered_by: request. Отдельный PDF, сайт или презентация не нужны. Конфигурацию не менять.

## Ожидаемый результат

- Пользователь отличает OpenCode, OMO, локальные инструкции и Paseo.
- Уменьшение избыточности предлагается только через подтверждённые настройки и понятные компромиссы.
- Внутреннее делегирование не смешивается с внешним запуском процесса.
- Оркестрация Paseo учитывает владельца изменений, границы workspace и завершение работ.

## Источники и наблюдения

- 2026-10-03: загружены skills ulw-research, dot-agents-context, omo-maintenance, paseo-help.
- `dot-agents-ctl list` показал смежный контекст omo-subagents-refining. Он посвящён настройке субагентов, а не четырёхтрековому обучению; создан отдельный omo-learning.
- Старая entry note omo-subagents-refining ссылается на legacy-путь конфигурации. Текущий maintenance skill требует проверять `~/.omo/omo.jsonc`; исторические заметки не считаются подтверждением актуального поведения.
- Context7 идентифицировал `/code-yeongyu/oh-my-openagent` как библиотеку OMO. Версия из индекса не доказывает установленную версию.

## Волны

Подготовка: проверена структура корпуса; создан контекст. Следующая фаза: параллельная проверка пользовательского интерфейса, настроек, агентного API и Paseo. Team-mode tools в текущем наборе отсутствуют; доступны фоновые исследователи.

Волна 1 запущена: отдельный librarian по пользовательским сценариям, explore по локальной конфигурации и источникам избыточности, librarian по внутреннему и внешнему интерфейсам, librarian по Paseo. Исследователи работают только на чтение; установка, изменение конфигурации, запуск платных smoke-сессий и создание рабочих агентов им не поручались.

Context7 вернул сведения с ветки `dev`, включая `default_mode` и изменённый team-first research skill. Это кандидаты для проверки, а не утверждения о локальной версии. Источник: https://github.com/code-yeongyu/oh-my-openagent/blob/dev/packages/omo-opencode/src/config/schema/default-mode.ts .

Прочитаны поставленные SKILL.md обоих workflow. Ветка расхождения закрыта для учебной рекомендации: используем ulw-plan и ulw-execute, не предлагаем start-work для этой установки. UI-переопределения остаются отдельной оговоркой.

Итог исследования: четыре исходных исследовательских сессии, две из них продолжены для уточнений, затем локальная проверка спорной регистрации. Отдельный writing-ревьюер проверил карту курса; замечания терминологии и критерия параллельной работы исправлены. Это ограниченное исследование для старта курса, не полный maximum-saturation протокол: все продвинутые ветки ниже явно отложены, а не названы исчерпанными.

Причинный вывод «главный источник всей духоты найден» не принимается: без конкретного раздражающего примера и измерения установлены только владельцы инструкций, а не универсальная причина симптомов.

- Локальный OpenCode `/doc`, effective config и каскадная отмена: отложены до практического занятия по интеграции. Потребуют отдельного изолированного запуска; не нужны для утверждения о документированном API.
- Отсутствующий `scripts/omo-maintenance` и schema export в cache: исследователь не нашёл их по ожидаемым путям. Диагноз «сломанная установка» не установлен; отдельная maintenance-задача, не препятствие учебным заметкам.
- Полный каталог автоматических skill-триггеров и legacy call_omo_agent: отложены как продвинутые темы; стартовые уроки не обещают полноты каталога.
- Эффективность textVerbosity/reasoning по моделям: не измерена. Нужен контролируемый эксперимент, а не вывод из наличия поля.
- Статистические, производительные и причинные гарантии не заявляются. Чтение исходников не заменяет runtime-тест отмены или измерение ускорения.

Наблюдения получены 2026-10-03. Для локальных фактов CLI и filesystem являются первичными источниками; независимое внешнее подтверждение состояния частного worktree неприменимо. Runtime-факты о поведении OMO пока не утверждаются.
