# Bash-сессия (zsh + prezto, не bash)

Bash-тул запускает неинтерактивный zsh с моими алиасами и опциями.
Bash-семантику не предполагать:

- `noclobber`: писать `>|`, дописывать `>>!` — включая редирект heredoc
  (`cat >| file <<'EOF'`). Временные файлы для этого не заводить.
- `grep`/`find` — обёртки (ugrep/bfs). ugrep молча пропускает .gitignore-файлы;
  нужен полный обход — `command grep -r`.
- Глоб регистронезависим (`CASE_GLOB` off) и падает целиком при отсутствии
  совпадений (`NOMATCH`). Перед деструктивной командой с глобом — показать раскрытие.
- `RC_QUOTES`: `''` внутри одинарных кавычек = литеральный `'`, не конец строки.
- `MULTIOS`: два `>` в одной команде пишут в оба файла.
- Скрипты исполняются zsh: массивы с индекса 1, `$var` без кавычек не разбивается
  на слова. Для bash-сниппетов — явный `bash -c '...'`.
- Алиасы раскрываются на этапе разбора: переопределение алиаса и его вызов
  в одной команде не сработают. Проверять в отдельном процессе.
